# 改进报告饼图图例与饼体重叠修复（两段图卡 2×2）— 测试与修改报告

**日期**：2026-08-24
**分支**：qi_analytic_improve
**任务**：改进报告第三部分「模块&特性占比（二级）」饼图存在标签（图例）与图（饼体）重叠问题；提交前代码审查进一步发现整体分析段（第二部分）同构缺陷，一并修复。

## 1. 任务概述

- **现象（第三部分）**：四图卡片沿用整体分析的 4 列窄栅格（卡片内宽 ~269px），二级饼图图例项形如「管控问题/管控子模块  48.2%」（canvas 实测最长 145px），图例列左缘落在 95px，侵入左置饼体（center 25% + radius 50%）右缘 127px，**重叠 32px**；一级图例较短（85px）不受影响。
- **现象（第二部分，审查轮发现）**：整体段当时维持 4 列不动，但 e2e 默认视口 1280×720 下整体图卡宿主实宽仅 ~229px（非注释声称的 ~270px），实测当前演示数据「管控问题  48.2%」图例列与饼环间隙已仅 +1px（按修正口径 −9px，**像素扫描证实 marker 与饼环实际重叠 ~8px**：第 89–133px 列区间彩色像素连成单一色带，环右缘 ~113px 与 marker 左缘 ~105px 相交）；若图例域名更长（如注释自举例）重叠可达 −36px。
- **最终修复**：改进报告页根节点新增页级类 `ir-page`（3 处模板），`report.css` 以 `.ir-page .mr-insight-chart-grid { grid-template-columns: 1fr 1fr; }` 使**整体分析段与领域分析段两段图卡均为 2×2 宽卡**；月度报告页同用 `mr-insight-chart-grid` 但不在 `ir-page` 作用域内，保持 4 列不受影响（实测复核）。HTML 导出整体段表格行同步改 2×50%。
- **防回归**：e2e 新增像素级断言 `pie_legend_gap ≥ 8px`，覆盖**全页 4 张饼图**（整体双饼 + 领域双饼）；间隙模型从 legend option 读取 right/padding/itemWidth/字号，与 `buildPieOption` 配置同源，调参自动跟随。

## 2. 计划与评审记录

- **方案候选（第 1 轮，AskUserQuestion 提交开发者）**：① 改 2×2 宽卡；② 压缩图例（截断/两行/缩小字号）；③ 饼体左移缩径。
- **评审结论（第 1 轮）**：开发者选定 **「改 2×2 宽卡（推荐）」**——不牺牲图例信息量（二级「领域/模块 xx.x%」完整展示），一次解决当前与未来更长的图例项。当时范围仅领域分析段，整体段维持 4 列。
- **评审结论（第 2 轮，审查驱动修订）**：提交前代码审查证实整体段在 4 列下重叠为在线缺陷（见 §3 发现 #1），开发者选定 **「整体段也改 2×2（推荐）」**，方案修订为页级两段 2×2；作用域由首版的 `.mr-section--domain` 段级覆盖改为 `.ir-page` 页级规则（月报页同用该栅格类，页级作用域一并消除"月报被误伤/需双向覆盖"的复杂度）。
- **方案偏离**：无。窄屏（≤1100px）回落单列系方案内补充（沿用本页既有媒体查询惯例）。
- **过程记录（如实）**：
  1. **CSS 级联顺序缺陷（阶段 2 自检发现）**：首版把 2×2 基础规则写在 `@media (max-width: 1100px)` 之后——同特异性后出现者胜，导致 900px 窄屏仍渲染 2 列。修复：基础规则上移至基础栅格规则之后（媒体查询之前），并在媒体查询内同特异性重申单列回落（页级规则 (0,2,0) 高于媒体查询内裸类 (0,1,0)，**媒体查询内的回落规则是承重的，不可删**——审查验证器亦复核确认）。未流入测试阶段。
  2. **视觉模型结论不可靠**：对修复前整体段截图问视觉模型"是否重叠"，得到模板化"无重叠、通常 5-10px 间隙"的回答，与几何测算矛盾；改用**逐行彩色像素游程扫描**（重叠列区间无背景色分隔，连成单一色带）拿到决定性证据。教训：像素证据 > 视觉模型话术。
  3. **测量脚本选错等待条件**：曾等待 `.mr-section--overall`，该类不存在（整体段节类为 `mr-section--insight`），15s 超时；改等 `[data-ir-save='overall']`。
  4. **jest 用例数漂移**：全量由上一任务 818/818 变为本次 819/819（0 失败；18 个套件因既有 ESM 问题无法运行，非本次引入），未深究，如实记录。
  5. 领域段图表默认空态需先点「导入」才挂载，冒烟脚本已按此流程（不点保存，不落库）。

## 8. 遗留风险与后续事项

1. **超长图例（审查发现 #7，PLAUSIBLE 暂不采纳）**：1101–1233px 视口带宿主 402–451px，二级图例 ≥20 汉字（maxText ~216px）时仍可能重叠——实测最窄 2 列档（1101px）当前余量 57px。属产品决策（图例截断/换行/宽度策略），运行时 e2e 守卫可捕获真实数据回归；不影响本次闭环。
2. **像素断言的近似性**：依赖 canvas `measureText` 与 echarts 几何口径（center/radius/legend 布局），echarts 升级若改布局算法需复核（当前经像素扫描双点校准，差 ≤5px，并以视确认双重验证）。
3. **视觉模型仅作辅证**：其对重叠判断曾给出与事实相反的模板化回答，后续此类判断以像素/几何证据为准。
4. 不影响闭环。
